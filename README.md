# LEVULA TI | Lucas Vargas - Soporte técnico informático

Portafolio personal de Lucas Vargas, técnico de soporte IT. Proyecto realizado para el curso de Frontend Developer de Coderhouse.

## Sitio publicado

https://lukiev91-spec.github.io/lv-technical-support/

## Páginas

- **Inicio:** presentación, servicios y galería (carousel).
- **Sobre mí:** experiencia y habilidades (acordeón).
- **Soporte:** soporte remoto y presencial.
- **Hardware:** diagnóstico e instalación de periféricos.
- **Administración:** usuarios, permisos, software y backups.

## Tecnologías

- HTML5 semántico
- CSS3: Flexbox, CSS Grid con `grid-template-areas` y media queries (mobile-first)
- SCSS con arquitectura en partials (`utilities/`, `base/`, `layout/`, `components/`) y `main.scss` como punto de entrada: variables, mixins, `@extend` y operadores
- Bootstrap 5.3 (vía CDN): navbar responsiva, carousel y acordeón
- AOS (Animate On Scroll) para animaciones al hacer scroll
- Google Fonts (Rajdhani)
